# Index

One line per document. Fetch the one that matches the task; don't fetch what you
don't need.

- `programming` — creating or changing blocks and mesocycles: the methodology,
  and the endpoints that write plans. Fetch before deciding anything about the
  plan.
- `session-generation` — writing today's session. Fetch when the user asks what
  to do today.
- `logging` — recording things in chat: retro sessions, corrections, user
  context, bodyweight. Fetch when the user reports something to record.
- `evaluation` — judging whether a mesocycle is working and what to do about it.
  Fetch for reviews and "is it working" questions.
- `charts` — the standard progress views and which reads feed them. Fetch when
  the user asks to see progress.
